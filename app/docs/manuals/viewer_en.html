Viewer Manual

Version 1.0 | English | ADKINTOR EAMS + FORESIGHT

What is Adkintor?

Adkintor is a tool that allows you to view maintenance information in read-only mode, AND report failures when you find a problem.

Your role is to consult and report. You don't execute the work, but you help keep the system updated with what you see.

What Can You Do?

1. Report Failures (EAMS → WORK ORDER → CREATE)

  • Report a failure when something is not working
  • Complete the 5 required fields:
    • REQUESTER: Who is reporting the failure?
    • PRIORITY: How urgent is it? (Emergency / Urgent / Normal / Planned)
    • AREA: Which area is the equipment in?
    • EQUIPMENT: Which equipment failed?
    • WORK DESCRIPTION: Describe the failure in detail
  • The WO is registered and your supervisor will review it
Note: You can only CREATE WOs. You cannot approve, execute, or close.

2. View Assets (EAMS → ASSET → ASSET MASTER)

  • View the complete asset list
  • View the asset hierarchy by area
  • Search for assets by ID or name
  • View detailed information (manufacturer, model, serial, criticality)
  • Print the master asset list
  • Print a datasheet for a specific asset
Note: You cannot create or modify assets.

3. View Work Orders (EAMS → WORK ORDER → SEARCH & REPORT)

  • Search WOs by number, asset, date, status, area, or priority
  • View the full list of WOs with all details
  • View a detailed report for each WO
  • Print WO reports
Note: You cannot approve, execute, or close WOs.

4. View Inventory (EAMS → INVENTORY → INVENTORY VIEWER)

  • View the complete SKU catalog
  • Filter by category or location
  • Search by SKU, description, manufacturer, or model
  • View transaction history for each SKU
  • Print the inventory report
Note: You cannot create, modify, or adjust stock.

5. View Calibrations (EAMS → CALIBRATIONS → CALIBRATION VIEWER)

  • View the list of calibration instruments
  • View calibration status (CRITICAL, UPCOMING, COMPLIANT)
  • View the calibration history for each instrument
  • Print the calibration report
Note: You cannot create or modify instruments or record calibrations.

6. View FORESIGHT - Work Orders (FORESIGHT → WORK ORDERS)

  • View the prioritized WO list
  • View tasks assigned to each technician
  • View system alerts
Note: You cannot assign, approve, or modify anything.
Important: Choosing the Right Priority

Selecting the correct priority is very important.

Not everything can be EMERGENCY or URGENT. If everything is urgent, then nothing is truly urgent. The system uses priority to decide what gets done first.

Priority When to Use
EMERGENCY Production is STOPPED. Nothing is working. Use this ONLY when the plant is down.
URGENT Production will be affected SOON. Use this when the problem will get worse quickly.
NORMAL No immediate impact. Use this for most routine issues.
PLANNED Scheduled preventive work. Use this for planned maintenance.
Not Sure Which Equipment? Use Plant Layout

If you are not sure which equipment is failing, you can:

  1. Go to EAMS → PLANT LAYOUT
  2. Check the map or diagram of the plant
  3. Find the equipment location
  4. Return to CREATE and select the correct equipment
Note: PLANT LAYOUT must be loaded by your supervisor. If the map is empty, ask your supervisor to upload it.
What You Cannot Do
  • Approve, execute, or close Work Orders (you can only CREATE)
  • Create, modify, or delete assets
  • Create, modify, or adjust inventory
  • Create or modify calibration instruments
  • Create or modify preventive maintenance plans
  • View financial KPIs (executives only)
  • View CONSULTING (administrators only)
Who Is This Role For?

The VIEWER role is designed for:

  • Plant operators who need to report failures
  • Office staff who need to consult maintenance information
  • Quality staff who review records
  • Procurement staff who need to check inventory
  • Any user who needs visibility but does not execute work
Reports You Can Export
  • Asset Report (PDF) → ASSET MASTER → PRINT MASTER LIST
  • Asset Datasheet (PDF) → ASSET MASTER → PRINT DATASHEET
  • Work Order Report (PDF) → SEARCH & REPORT → VIEW → PRINT TO PDF
  • Inventory Report (PDF) → INVENTORY VIEWER → PRINT
  • Calibration Report (PDF) → CALIBRATION VIEWER → PRINT
Golden Rules
  • Report everything. Imperfect data is better than no data.
  • If you see something incorrect, notify your supervisor.
  • Do not share sensitive information outside the organization.
  • If you are unsure about something, ask your supervisor.
