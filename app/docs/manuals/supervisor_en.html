What is Adkintor?

Adkintor is a tool that helps you manage your plant's maintenance. It allows you to approve and close Work Orders, plan and release preventive maintenance, manage inventory and calibrations, and monitor your team's performance.

ADKINTOR IS A GUIDE. YOU HAVE THE FINAL SAY.
Your Main Responsibilities

Technicians execute the work. You supervise, approve, plan, and ensure the system stays up to date.

At the Start of Your Shift

Task 1: Approve New Work Orders

  1. Go to EAMS → WORK ORDER
  2. Click "APPROVE"
  3. Review new WOs since your last review
  4. For each WO:
    • EMERGENCY → Approve NOW + assign technician
    • URGENT → Approve within 4 hours + assign technician
    • NORMAL → Approve within 24 hours + assign technician
    • PLANNED → Approve within 24 hours + assign technician
  5. Click "APPROVE & RELEASE" (or "REJECT" with a mandatory comment)
Note: Approved WOs are assigned to the technician and will appear in "MY TASKS".

Task 2: Review Your Team's Tasks

  1. Go to FORESIGHT → WORK ORDERS
  2. Click the "MY TASKS" tab
  3. Select each technician to see their assigned task list
  4. If someone has too many tasks, redistribute manually
At the End of Your Shift

Task 3: Close Completed Work Orders

  1. Go to EAMS → WORK ORDER
  2. Click "CLOSE"
  3. Review WOs that technicians marked as "COMPLETED"
  4. For each WO, verify:
    • Hours are reasonable
    • Consumed parts are correct
    • Work description is clear
  5. If everything is correct → "AUTHORIZE FINAL CLOSURE & ARCHIVE"
  6. If something is wrong → Leave a comment and close
Once a Week

Task 4: Release Preventive Maintenance

  1. Go to EAMS → PREVENTIVE → RELEASE
  2. Select next week
  3. Click "LOAD PLAN"
  4. Review the scheduled tasks
  5. Select the tasks you want to release
  6. Click "RELEASE SELECTED"
  7. In the confirmation modal, check BOTH boxes:
    • ☑ "Are the required spare parts and materials available for the selected work orders?"
    • ☑ "Has production been notified and downtime confirmed for the affected technical locations?"
  8. Click "CONFIRM & RELEASE"
Note: Released tasks become WOs in OPEN status. You must then assign them to technicians in APPROVE.

Task 5: Review Old or Urgent WOs

  1. Go to FORESIGHT → WORK ORDERS
  2. Click the "ALERTS" tab
  3. Check for unattended or urgent WOs
  4. Take action as needed

Task 6: Review Upcoming Calibrations

  1. Go to EAMS → CALIBRATIONS → MANAGER
  2. Review the status heatmap:
    • CRITICAL: < 30 days until due
    • UPCOMING: 30-90 days until due
    • COMPLIANT: > 90 days until due
  3. Schedule necessary calibrations
Once a Year (Strategic Planning)

Task 7: Review Annual Preventive Plan

  1. Go to EAMS → PREVENTIVE → PLANNER
  2. Select next year
  3. Click "GENERATE" (system auto-generates the plan)
  4. The system considers:
    • Equipment criticality (A, B, C)
    • Groups tasks that are close in time
    • Distributes evenly across 52 weeks
    • Avoids scheduling major maintenance during peak season
  5. Review the weekly workload heatmap
  6. If needed, make manual adjustments by moving tasks between weeks
  7. When satisfied, click "LOCK" (plan becomes permanent and cannot be modified)
⚠️ CAUTION! Once you lock the plan, you can NEVER modify it again.

Task 8: Add Maintenance for New Equipment

If new equipment arrives mid-year:

  1. Go to EAMS → PREVENTIVE → MANUAL
  2. Search for the new asset (Technical Location)
  3. Select the desired frequency
  4. Select the target years
  5. The system generates tasks for the remainder of the year

Task 9: Create Maintenance Activities

  1. Go to EAMS → PREVENTIVE → ACTIVITY
  2. Search for an existing Technical Location
  3. Click "BUILD" to view its strategies
  4. To create a new activity:
    • Click "CREATE NEW ACTIVITY"
    • Select the equipment
    • Describe the instruction
    • Define the acceptance standard
    • Estimate time in hours
  5. You can clone activities to similar equipment to save time
Monthly (First Week, 15 Minutes)

Task 10: Review KPIs

  1. Go to FORESIGHT → KPI
  2. Select the previous month
  3. Review these indicators:
    • Availability: Is it above 90%?
    • PM Compliance: Is it above 90%?
    • MTBF: Is it above 15 days?
    • MTTR: Is it below 4 hours?
    • OTIF: Is it above 90%?
  4. Review financial analysis:
    • Budget vs Actual: Are we within budget?
    • Top 5 assets by cost: Where is the money going?
System Configuration

As a Supervisor, you have access to CONFIG:

  1. Go to EAMS → CONFIG
  2. You can modify:
    • Technician names
    • Approver names
    • Notification email addresses
    • Other system settings
Asset Management (Important Information)
  • Only Technical Locations (TL) have preventive maintenance.
  • Assets have a hierarchy: Area → TL → Main Equipment → Sub-Assembly → Component.
  • Each asset has a criticality level (A - CRITICAL, B - IMPORTANT, C - STANDARD).
  • Criticality is calculated automatically when creating the asset.

To create a new asset:

  1. Go to EAMS → ASSET → ADD ASSET
  2. Complete the required fields
  3. The system auto-generates the Asset ID
  4. Criticality is calculated based on the evaluation matrix
Caution: The Sweeper

The system has an automatic SWEEPER that:

  • Closes preventive WOs that have been open for more than one month
  • Marks them as "not performed"
If you don't want the system to auto-close WOs, check the sweeper configuration. You can run it manually from EAMS → PREVENTIVE → SWEEPER.
Common Problems and How to Solve Them
Problem Solution
The system is slow Ask the technician to:
→ Click the ADKINTOR logo (clears the cache)
→ Close other tabs
→ Use Chrome (not Edge, not Firefox)
If still slow → Report to support@adkintor.com
A WO was approved but never executed → Verify the technician is still on the team
→ Check if parts were available (EAMS → INVENTORY → INVENTORY HUB)
→ If parts were missing, create a purchase order (EAMS → INVENTORY → PROCUREMENT)

Note: WOs cannot be reassigned in the system. If the technician left, you must create a new WO and close the old one.
Preventive WOs are piling up, no time → Don't release all PMs at once. Only critical ones (A and B)
→ Move C-class PMs to next month
→ If this happens every month → Request more technicians or outsource
The sweeper closed WOs automatically → Go to EAMS → PREVENTIVE → SWEEPER
→ Check the "Transaction Audit Trail" to see what was closed
→ If it was a mistake, open a new WO with high priority
You disagree with an Adkintor recommendation → Recommendations are suggestions, not commands. You are in charge.
→ Adkintor is designed to give you good data-based suggestions.
→ If you disagree, simply ignore it and follow your judgment.
Best Practices (Do These)
  • Review the prioritized WO list every morning before assigning
  • Always comment when rejecting an approval (it's mandatory)
  • Release preventive maintenance on Fridays for the following week
  • Review the sweeper periodically to keep the system clean
  • If a technician is consistently slow, check if they need training
TIP: Create a filter in your corporate email so all emails from Adkintor go to a specific folder. This makes them easy to review.
Common Mistakes (Don't Do These)
  • The system will NOT let you approve a WO without assigning a technician (it's blocked)
  • The system does NOT allow technicians to close their own WOs (it's blocked)
  • KPI history is NOT lost. You can consult previous months.
  • Don't ignore Adkintor recommendations without considering them. They are based on data.
  • Don't ignore the sweeper. If it's active, it will auto-close WOs after one month.
What You Should Not Touch (Blocked by Your Role)
  • SYS Dashboard (admin only)
  • System Diagnostic (admin only)
  • CONSULTING (account administrator only)
Golden Rules
  • Your team trusts you. Make sure the system trusts them too.
  • The data you approve feeds the KPIs. Bad data = bad KPIs.
  • Adkintor doesn't replace your judgment. It's one more tool in your toolbox.
  • Keep the system clean (SWEEPER) so recommendations stay accurate.
