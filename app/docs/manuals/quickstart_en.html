Quick Start Guide

Version 1.0 | English | ADKINTOR EAMS + FORESIGHT

What is this guide for?

This guide is for EMERGENCIES. When you don't have time to read the full manual, this is what you need to know to keep the system running.

ALL roles can use this guide.

System Access
  1. Open your browser (use CHROME)
  2. Go to: https://www.adkintor.com/app
  3. Enter your corporate email and password
  4. Click "SIGN IN"
Forgot your password?
→ Click "Forgot Password?" and follow the instructions
→ Or ask your supervisor to reset it
If Production Stops (Emergency)
  1. Go to EAMS → WORK ORDER → CREATE
  2. Priority: EMERGENCY
  3. In WORK DESCRIPTION, write: "PRODUCTION DOWN - [affected equipment]"
  4. Click "SUBMIT WORK ORDER"
  5. Your supervisor will receive an immediate alert
Important: Time is critical. Don't wait to report.
If You Find a Failure (Not Emergency)
  1. Go to EAMS → WORK ORDER → CREATE
  2. Priority: URGENT, NORMAL, or PLANNED (choose the right one)
  3. Describe the failure in WORK DESCRIPTION
  4. Click "SUBMIT WORK ORDER"
If the System is Slow
  1. Click the ADKINTOR logo (clears the cache)
  2. Close other tabs
  3. If still slow, report to support@adkintor.com
If the System is Down
  1. Write everything on paper:
    • WO, hours, parts, description
  2. Enter the data when the system is back
    • You have 24 hours to do this
If You Have a Question
  1. Ask your supervisor
  2. Or email support@adkintor.com
What Does Each Role Do?
Role Responsibilities
Technician Report failures, execute work, close WOs
Supervisor Approve WOs, release PMs, review team, close WOs
Executive Review KPIs, make strategic decisions
Viewer Report failures, view information
Remember
  • Adkintor is a guide. Your supervisor has the final say.
  • Report everything. Imperfect data is better than no data.
  • Do not share your password with anyone.
  • If you don't know something, ask.
