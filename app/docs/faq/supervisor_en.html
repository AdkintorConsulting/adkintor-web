FAQ - Supervisor

Version 1.0 | English | ADKINTOR EAMS + FORESIGHT

How do I approve a WO?

Go to EAMS → WORK ORDER → APPROVE. Review pending WOs, select one, assign a technician, and click "APPROVE & RELEASE". If not ok, use "REJECT" with a mandatory comment.

How do I close a WO?

Go to EAMS → WORK ORDER → CLOSE. Review WOs marked as "COMPLETED" by technicians. Verify hours, parts, and description. If everything is ok → "AUTHORIZE FINAL CLOSURE & ARCHIVE". If something is wrong → leave a comment and ask the technician to fix it.

How do I release preventive maintenance?

Go to EAMS → PREVENTIVE → RELEASE. Select the week, click "LOAD PLAN", select the tasks, and click "RELEASE SELECTED". Check both checkboxes and confirm.

Are released WOs automatically assigned to technicians?

No. They remain in OPEN status. You must then go to APPROVE and manually assign them to technicians.

How do I check my team's workload?

Go to FORESIGHT → WORK ORDERS → MY TASKS. Select each technician to see their assigned task list.

What is the sweeper and how do I use it?

The sweeper is a tool that closes abandoned preventive WOs. Go to EAMS → PREVENTIVE → SWEEPER to review the history. The automatic sweeper closes WOs after one month. You can run it manually with "FORCE SWEEP".

Can I reassign a WO to another technician?

No. WOs cannot be reassigned in the system. If a technician left, you must create a new WO and close the old one.

What if the system is slow?
  1. Click the ADKINTOR logo (clears the cache)
  2. Close other tabs
  3. Use Chrome

If still slow, report to support@adkintor.com

How do I create an annual preventive plan?

Go to EAMS → PREVENTIVE → PLANNER. Select next year and click "GENERATE". The system auto-generates the plan. Review the heatmap and make manual adjustments if needed. When satisfied, click "LOCK" (you cannot modify it after).

What if new equipment arrives mid-year?

Go to EAMS → PREVENTIVE → MANUAL. Search for the new asset (Technical Location). Select the desired frequency and target years. The system generates tasks for the remainder of the year.

How do I create maintenance activities?

Go to EAMS → PREVENTIVE → ACTIVITY. Search for a Technical Location, click "BUILD", then click "CREATE NEW ACTIVITY". Describe the instruction, standard, and estimated time.

Does the executive see the same KPIs I do?

The executive has access to KPI, but their role is strategic. You see the same operational KPIs. The executive can see them too.

What if I disagree with an Adkintor recommendation?

Recommendations are data-based suggestions. You have the final say. If you disagree, simply ignore it.

How do I configure email notifications?

Go to EAMS → CONFIG. There you can modify notification emails, technician names, approvers, and other settings.

What if the sweeper closes WOs it shouldn't have?

Go to EAMS → PREVENTIVE → SWEEPER. Check the "Transaction Audit Trail" to see what was closed. If it was a mistake, open a new WO with high priority.
