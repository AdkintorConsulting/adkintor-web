# ADKINTOR Web

Sitio web oficial de ADKINTOR — Software EAMS & FORESIGHT para mantenimiento industrial.

## Estructura del repositorio

- `es/` → Páginas en español (idioma principal)
- `en/` → Páginas en inglés
- `js/lang-switch.js` → Selector de idioma (recuerda preferencia en localStorage)
- `app/` → Aplicación interna (login, módulos EAMS) — no modificar
- `index.html` (raíz) → Redirige a `/es/` o `/en/` según preferencia

## Cómo editar el sitio

Todo se edita directamente desde la web de GitHub:
1. Abrir el archivo deseado
2. Clic en el lápiz ✏️
3. Modificar el contenido
4. Escribir un mensaje de commit y hacer clic en "Commit changes"

GitHub Pages redespliega automáticamente en 1–3 minutos.
